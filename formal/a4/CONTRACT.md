# a4 候选语义契约（父级钉住，2026-10-08 夜）

目的：检验 a4 的"一个判据"能否在**不加特殊规则**的情况下，复现 a3（`formal/a3/CONTRACT.md` K1–K14）在 merge 与 auth 模型上的全部结论。a4 是重组，不应改变语义；若某条性质在 a4 与 a3 下结果不同，这正是要找的东西。

## 物与断言

- 物：内容（哈希命名、不可变）与账 L（只增长）。项 = (义务 o, 键 k)，键定义同 K1。
- 断言只有一种：`a = ⟨author, subject, value, premises, pos⟩`。
  - subject ∈ 项 (o,k) | 节点义务 (n,o) | 名字（trunk、权限、计划、写者槽…）。
  - value：对项是 pass / fail / BLOCK / OK / 免（无执行的肯定）/ 缓判 / 归因结果；对名字是新值。
  - premises：作者声称看过的断言集合（引用 pos），对名字至少含前值。

## 唯一判据

```
Counts(a, t) ≜ Authorized(a, t) ∧ Informed(a, t) ∧ Recused(a)
σ 成 ⟺ O(σ) 的每一项在 t 都有一条 Counts 的肯定
```

**Authorized(a, t)**（有权）
- 名字上的断言：作者在 t 有效地拥有该名字的权限（K8 原样：签发时生效、持续有效、链断永久断、根在 L[0]）。
- 项上的肯定：作者属于该义务的**作证者表** `Witnesses(o)`（策略，入账于 L[0]）：
  - 执行义务：受信执行器；
  - 判断义务（评审、人工验收）：档位 ≥ 义务要求的评审者；
  - 免（无执行的肯定）：按 K9 权限表；**清除已有否定的免**只有 owner；
  - 状态不变式：只有执行器；免不可用；只能缓判（缓判是对变更义务"不增欠"的免，不是对状态项的肯定）。

**Informed(a, t)**（知情）
- 令 `Rel(a)` 为与 a 相关的断言：
  1. 对项 (o,k)（属于节点 n）上的肯定：所有位置在 t 之前的、n 上同义务 o 的否定（**任意键**），以及同项 (o,k) 上的全部断言；
  2. 对名字上的断言：该名字此前的值；
  3. 对 trunk 前进：trunk 前值，以及变更 O(PRE→s) 各项在 t 时的状态（由 1 递归给出）。
- a 在 t 知情 ⟺ `Rel(a)` 中每一条位置 < t 的**否定或新值** r 都已被"清除"：
  - r 是判断类否定：a 的 premises 引用了 r，且 a 的作者档位 ≥ r 的作者；或存在另一条满足此条件、位置在 r 之后的肯定被 a 引用；
  - r 是执行类否定（键 k'）：存在位置在 r 之后、主语为 (o,k') 的受信执行器重跑断言（**归因**），且 a 引用该归因；归因结果为 pass ⇒ (n,o) 记为 ⊤，任何肯定都不 Count，直到律改判定规则；
  - r 是名字的新值：a 的 premises 含 r（即 CAS 前值正确）。
- **注意**：知情在**每个 t 重新求值**（项状态视图），但已经发生的 trunk 前进按其位置求值，不改写历史。所以一条后来的否定会让项回到欠，但不会撤销已发生的合入（成为逃逸台账条目）。

**Recused(a)**（回避）
- `author(a) ∉ Authors(subject)`，其中 Authors 包括：被观内容的作者；所执行检查闭包的作者；对免、降级、缓判：同一 DAG 当前或曾经持有写者槽的全部主体（K9，父级除外）。

## 指针

trunk 前进是名字上的断言，Counts 外加：变更 PRE→s 成，且不增欠 `D(s) ⊆ D(PRE)`（K3，按项）。L[0] 命名 s₀ 并带创世观察（K4）。

## 不在 a4 判据内的东西（移入策略）

K7 反事实规格、K10 诱饵、K11 默认值、K12 声明闭包、K14 判定与执行分离：都是 L[0] 中律的内容。

## 检验要求

- a4 模式里，合入、豁免、解封、授权的守卫**只能**通过一个通用的 `Counts` 定义；不得保留 a3 的特殊分支（封的继承、"只有 owner 可免已封"等应由 Rel/Witnesses 推出）。
- 原有真值性质一字不改；比较 a3 与 a4 的结果。
- 消融：分别去掉 Authorized、Informed、Recused，以及 Rel 的第 1、2、3 条；每个消融都应翻转至少一个性质，否则该部分多余。
- 分歧分类：(a) Rel 太窄 → 漏洞；(b) Rel 太宽 → 活锁或合法合入见证失败；(c) a3 某特殊规则不可约 → 记录哪一条、为什么。
