# aw2090 — concurrent-adopt test independent of the merge-lock winner

User-facing change: none (test-only; no src/ change).

Changed existing test (ruling #2817):

- `test/adoptwait.test.ts` — "AW #2090: two concurrent CLI adopts share each request's 600ms total budget".
  It required both adopters to time out on the ledger lock. After the test releases the merge lock, the adopter
  that acquires it waits on the held ledger lock; when the later-started adopter wins, the earlier one exhausts its
  own budget on the merge lock held by that adopter (#2812 log). The test now accepts a merge-lock or ledger-lock
  timeout per adopter, and requires a named merge-lock holder to be the test or the other adopter. Exit 75, the
  per-request timing bound (budget + 1 s), pending-marker cleanup and the unchanged ledger are asserted as before.
